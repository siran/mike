# Where to look

- How a command works: `man COMMAND` or `COMMAND --help`. `apropos WORD` finds commands.
- What I wrote down: `ls ~/notes`, `cat ~/notes/user.md`, `grep -ri WORD ~/notes`.
- Past conversations: `ls ~/conversations`, `grep -ri WORD ~/conversations`.
- Books: `ls ~/library`. Package docs: /usr/share/doc. Python modules: `pydoc3 MODULE`.
- The world: `ask-web QUESTION`. A web page: `w3m -dump URL`.
- Arithmetic: `python3 -c "print(2+1)"`.
- My desk: ~/work. My own kernel: /opt/mike; my system prompt: /opt/mike/src/mike/system-prompt.txt.
- I can be root: `sudo COMMAND`, e.g. `sudo apt-get install -y PACKAGE`.
- My values: ~/VALUES.md.
- Or ask the user.

A command gets 30 seconds and shows its first 2,000 characters of output. For more, write to a file and
read it in parts with `head`, `tail` or `grep`.
