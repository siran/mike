# MIK-0 retrieval: initial held-out results

## Result

Neither tested model used the search tool under this action protocol. Each scored 0/100 in both the enabled and disabled conditions, with no evidence-supported correct answers. The predeclared feasibility gate was 50/100 evidence-supported correct answers; neither model passed. This is a negative result for these particular model–prompt–protocol combinations. Since no retrieved evidence reached either model, it does **not** test whether either could combine retrieved facts, whether tools reduce needed capacity, or the minimality of reasoning.

For each 0/100 score, the marginal Wilson 95% interval is approximately 0–3.7% on this generator; the 100 questions share a template and one generated world, so this interval does not imply coverage of broader tasks. Both conditions produced identical first-step raw outputs for all 100 paired questions for each model. All comparisons therefore have zero tasks solved by either model, and zero solved exclusively by one condition. A task-specific handwritten four-relation traversal scored 100/100 with lookup and 0/100 without lookup; it is a purpose-built control, not a general intelligence system or a learned model.

## Setup and failure analysis

The final world used seed `20261029` and canonical SHA-256 `23833d5d4ab83c0b8ec5aac1c13610800873982591674135cf2243ea93b1e5fb`. It contained 100 four-hop chains plus 2,000 unrelated facts. Each search returns facts for one exact subject, never a multi-hop solution. The model sees the question and its own observations, not the answer key. The separate smoke world used seed `10728`: on two questions the 135M model emitted two invalid actions; the 360M model produced one invalid action and one unsupported answer. The held-out protocol was documented before the evaluation.

The 135M model often repeated the JSON input state rather than emitting an action. The 360M model sometimes emitted an answer whose `evidence` was a list of objects rather than the required list of record-ID strings; other times it returned the starting object identifier as the final property. The validator did not silently repair either format. Both models' 0 searches mean the enabled and disabled conditions were observationally identical at the point of failure; these results cannot separate language, formatting, instruction following, retrieval strategy, and downstream reasoning.

Both models were frozen, float32, greedy decoding, maximum 96 new tokens per decision, maximum six decisions, on an AMD Ryzen 7 7730U CPU with 32 GB RAM, Windows 11, Python 3.14.2, PyTorch 2.14.1+cpu, and Transformers 4.57.6. The resolved model snapshots are `12fd25f77366fa6b3b4b768ec3050bf629380bac` (135M) and `a10cc1512eabd3dde888204e902eca88bddb4951` (360M). The 135M runs used four PyTorch threads each and the 360M runs two each; runs overlapped, so timings are not controlled head-to-head speed measurements. Model loading, world generation, and per-task index construction are excluded. Training compute, FLOPs, energy, peak memory, storage and human implementation effort were not measured. Cost per successful task is undefined because no task was solved.

The machine-readable [comparison](mik0-comparison.json) includes per-run metadata, paired counts and aggregate measurements. Generated answer keys and full per-step JSONL traces remain in local ignored `data/` and `traces/`; the fixed seeds and recorded model snapshots support regeneration. The generated worlds are hidden from the model, but published seeds are not cryptographic secrets.

## What remains open

The fixed measurement tool is an interface fixture; rule discovery and selecting informative experiments are not evaluated. Contradiction, misleading evidence, task composition, persistent learning, calibration, multiple independent world seeds, stronger reference models and total-system-cost accounting remain untested. Before the next final evaluation, use a separate development world to establish a more reliable action interface, then test reasoning with evidence supplied directly as a separate condition as well as retrieved incrementally. Freeze the revised protocol and use fresh held-out worlds; do not reinterpret these results as evidence that small models cannot reason.
